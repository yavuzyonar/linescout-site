# OddsLighthouse

A static site for OddsLighthouse, an independent US sports betting / online casino content site. Hosted free on GitHub Pages.

## Structure

- `index.html`, `about.html`, `disclosure.html`, `responsible-gambling.html`, `privacy.html` — core pages
- `articles/` — one HTML file per article, plus `articles/manifest.json` which drives the homepage and guides-index listings
- `assets/style.css`, `assets/main.js` — shared styling and behavior (age gate, article listing renderer)

## Adding a new article

1. Copy an existing file in `articles/` as a template.
2. Add a matching entry to `articles/manifest.json` (slug, title, excerpt, category, date, readTime).
3. Add a header image at `assets/article-images/<slug>.svg` (see `assets/gen_article_images.py` for style reference).
4. Run the SEO pipeline, in order: `python3 assets/gen_og_images.py`, `python3 assets/gen_sitemap.py`, `python3 assets/inject_seo_head.py`.
5. Commit and push — GitHub Pages redeploys automatically within about a minute.

This repo is also written to automatically by a daily scheduled Claude task (see project notes) that adds two new evergreen articles per day (one sports betting, one casino) and pushes them here directly, including the SEO pipeline steps above.

## SEO

- `robots.txt` and `sitemap.xml` (auto-generated) at the site root.
- Every page has a self-referencing canonical tag, Open Graph + Twitter Card tags, and a favicon (`assets/favicon.svg` + PNG fallbacks).
- Every page carries JSON-LD structured data: `Organization`/`WebSite` on the homepage, `Article` + `BreadcrumbList` on article pages, `BreadcrumbList` elsewhere.
- These are generated/refreshed by `assets/inject_seo_head.py` inside a `<!-- SEO:START -->`/`<!-- SEO:END -->` block in each page's `<head>` — don't hand-edit that block, re-run the script instead.
- Per-article Open Graph share images (1200x630) are generated by `assets/gen_og_images.py` into `assets/og/`.
- **Not yet done:** the site isn't verified/submitted in Google Search Console or Bing Webmaster Tools, so `sitemap.xml` isn't being actively crawled from a submitted sitemap yet — see the audit notes for how to do this.
